⚙️ JAVASCRIPT FEATURES (197 Lines Total)

All features implemented in pure vanilla JavaScript with no external libraries:

1. Mobile Menu (initMobileMenu)
   • Toggle button event listener
   • ARIA state management (aria-expanded)
   • Focus trap implementation
   • Overlay click-to-close
   • Escape key handler
   • Focus management

2. Reveal Animations (initRevealAnimations)
   • Single IntersectionObserver for efficiency
   • Observes all .reveal elements
   • Adds .reveal--visible class when in viewport
   • Unobserves after reveal (performance)
   • Threshold: 15% with -50px bottom margin

3. Accessible Carousel (initCarousel)
   • Auto-rotation with 5-second intervals
   • Previous/Next button controls
   • Dynamic dot navigation
   • Keyboard arrow key support
   • Pause on hover and focus
   • ARIA attributes management
   • Slide visibility toggling
   • Reset autoplay on manual interaction

4. Lazy Loading (initLazyLoad)
   • IntersectionObserver for images
   • Loads images as they approach viewport
   • 50px rootMargin for smooth loading
   • data-src attribute pattern

5. Active Navigation (initActiveNav)
   • Highlights current page in navigation
   • Sets aria-current="page"
   • Adds visual styling (bold, color)

🚀 QUICK START GUIDE

1. Install Dependencies:
   $ npm install

2. Build CSS:
   $ npm run build:css
   # OR
   $ ./build.sh

3. Development (Watch Mode):
   $ npm run watch:css

4. Preview Site:
   $ cd site
   $ python3 -m http.server 8000
   # OR
   $ npx http-server site -p 8000

5. Open Browser:
   http://localhost:8000

🎓 HOW TO DUPLICATE FOR ANOTHER SCHOOL

Step 1: Copy Configuration
  $ cp config.json.sample config.json

Step 2: Edit config.json
  • Update site.title and site.description
  • Modify navigation links
  • Change hero content and CTAs
  • Update program cards
  • Edit events list
  • Adjust statistics
  • Update footer information
  • Change contact details
  • Update social media links

Step 3: Replace Images
  Place your school's images in site/assets/images/:
  • logo.svg or logo.png
  • hero.jpg
  • academics.jpg
  • admissions.jpg
  • student-life.jpg
  • event1.jpg, event2.jpg, event3.jpg

Step 4: Customize Colors (Optional)
  Edit tailwind.config.js:
  • Change primary colors
  • Change secondary colors
  • Adjust other theme settings

Step 5: Rebuild
  $ npm run build:css

Step 6: Deploy
  Upload the site/ directory to your hosting provider
